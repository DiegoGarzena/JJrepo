name=Points Along 3D Line
qgisMinimumVersion=3.22
qgisMaximumVersion=3.99
description=Generates points at constant 3D (surface) distances along lines, with elevation from a DTM raster and detailed geometry attributes.
version=1.1.0
author=Diego Garzena
email=dieggarz@gmail.com
about=Processing algorithm designed for geophysics, surveying, civil engineering and geotechnics. It places points at fixed 3D distances along lines, measured on the terrain surface, using a DTM raster for elevation. No pre-processing is needed: lines are densified and draped on the DTM internally with bilinear interpolation. The output attribute table includes line_id, part_id, seq_id, coordinates in any CRS, elevation, 2D and 3D step and cumulative distances, elevation difference, signed slope (degrees and percent) and azimuth.

changelog=1.1.0
    - No pre-processing needed any more: lines are densified and draped on the DTM internally (no need for Densify by interval / Set Z value from raster)
    - Bilinear interpolation of the DTM instead of nearest neighbour, which avoids a staircase profile and an overestimated 3D length
    - The DTM can have a different CRS from the lines; band selection added
    - Slope is now signed (positive uphill, negative downhill)
    - New options: start offset, include end point, densification step
    - New part_id attribute; seq_id restarts for each part of multipart lines
    - Input is now a feature source (selected features only and temporary layers are supported); progress bar added
    - NoData in the DTM is no longer turned into elevation 0
    - New option Keep points beyond the DTM edge (unchecked by default): lines extending past the DTM keep their points with the elevation of the last valid vertex, flagged in the new z_extrap field
    - Prominent red warning in the log when lines are partly or completely outside the DTM
    - Clearer help about densification and the densification step
    - Intervals of 0 or less and geographic CRS inputs are rejected with a clear message
    - Geographic coordinates are now written with 7 decimals instead of 4
    - 2D distances are now measured along the path, consistently with the 3D distances
    - Unit tests for the geometric core, compatibility with newer QGIS APIs
    1.0.1
    - Added the attribute table fields (line_id, seq_id, coordinates, elevation, 2D/3D distances, elevation difference, slope, azimuth); previously the table was empty
    1.0.0
    - Initial public version
